# KT2
Это тестовое задание на стажировку в KODE.
Проект содержит сайт с актуальным списком всех работников компании.

Задание: https://github.com/Hexlet/ru-test-assignments/blob/main/frontend/kode/trainee-test-frontend.md
## Было выполнено: 
Создать локальный сайт-одностраничник, подключить API к серверу со списком информации для задания, добавить способы фильтрации поиска по имени среди списка.
## Было не выполнено:
Не будет проработанной визуальной обработки, отображения скелета, иконки ошибки поиска, иконки отсутствия найденных результатов; вкладки профиля человека (контакты).

## Как запустить проект
1. Склонировать репозиторий или скачать его архив.
2. Открыть папку проекта.
3. Запустить файл `index.html` в браузере (двойным щелчком мыши).

**Дополнительная установка не требуется.**
Проект использует HTML, CSS и JavaScript и работает локально в браузере.
Проверено вручную по инструкции.
